# Customer Shopping Behaviour Analysis

An end-to-end data analytics project to analyze customer purchasing patterns and generate actionable business insights using Python, SQL, and data visualization tools.

## 🚀 Features
- Data cleaning and preprocessing of raw transaction data
- Exploratory Data Analysis (EDA) to identify trends and patterns
- Customer segmentation based on purchasing behavior
- Analysis of high-value customers and product performance
- Data-driven insights for improving sales and marketing strategies

## 🛠 Tech Stack
- Python (Pandas, NumPy)
- SQL (MySQL)
- Power BI / Matplotlib
- Jupyter Notebook

## 📊 Key Insights
- Identified top-performing products and categories
- Detected high-value customers contributing most revenue
- Analyzed seasonal and revenue trends
- Provided insights to optimize business decisions

## 📁 Project Structure
- `data/` → raw and processed datasets (sample only)
- `notebooks/` → Jupyter notebooks for analysis
- `scripts/` → Python scripts
- `visuals/` → charts and dashboards
- `README.md` → project documentation
